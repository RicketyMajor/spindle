# Spindle

Reproductor de música local para Android, sin algoritmos. Se navega como un iPod, con estética de terminal: lo que suena es siempre algo que elegiste.

- `android/`: la app Spindle (Kotlin + Jetpack Compose + Media3).
- `station/`: **Spindle Station**, la CLI de PC que baja, etiqueta y organiza la música (yt-dlp + beets).

Especificación completa: [`docs/SPEC.md`](docs/SPEC.md).
